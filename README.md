## 🚀 How to Run Locally in Front of the Professor
1. **One-Click Run:** Double-click `run_preview.bat` in the project folder. It launches the local server and opens your browser directly to:
   `http://localhost:8000`
2. **Command Line:**
   ```powershell
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in Chrome or Edge.
